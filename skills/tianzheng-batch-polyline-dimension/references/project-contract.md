# 项目合同

## 能力身份

- 项目实体：`auto-CAD-project-loop`
- 命令包：`CAD-CMD-BATCH-POLYLINE-DIM-V1`
- 用户名称：`自动批量多段线尺寸`
- 项目根：由调用方提供；默认使用本机登记的天正自动化项目根。
- Skill 是稳定入口和执行路由，不是第二份业务实现。

## 固定架构

### 业务层

1. 运行时发现目标多段线以及可标注 ARC/LINE 段。
2. 根据几何、拓扑、闭合内外侧和原生 grip 响应决定标注语义与放置轴。
3. 生成原生 `TDbDimension2`，建立实时 source mapping，并通过端点关联门。
4. 第一遍对普通对象使用共同外侧尺寸带公式。
5. 第二遍只处理运行时识别出的异常对象：容量不足、尖角坍缩、错误侧、文字锚点落线或局部拥挤。
6. 对异常文字只移动 grip 4；不重新扰动已验收的普通对象。

### 观察层

在阶段边界记录命令是否真正被 CAD 接收和完成、对象集合、语义、端点、grip、耗时和截图。观察层不得修改公式或对象。快速稳定步骤不增加轮询；发生疑难失败时才启用专项探针。

## 标准公式约束

### 普通排版

- 优先统一到多段线外侧；仅在真实几何容量或碰撞证据存在时换侧。
- 偏移量以文字高度 `H`、局部半径、弦长、夹角、邻接拓扑和闭合内外侧形成无量纲规则。
- 已通过对象冻结；失败子集隔离处理。

### 特殊角度救援

- 必须先获得端点有效的原生角度候选，再修姿态和文字。
- 文字跟随标注弧线的普通关系不被手动打散。
- 当特殊候选的文字定位点仍落于标注线上时，以同一源多段线、共享端点、rank-2、角度语义正确的邻近对象作为 peer。
- 将 peer 的文字相对其标注弧线的法向距离按双方实时 `H` 归一化，求得目标 grip-4 的 WCS `DX/DY`。
- planner 输出 WCS delta；执行器原样消费。禁止控制器二次投影、交换轴或重算向量。

## 禁止固化的底板特征

最终业务代码不得引用固定 handle、WCS 坐标、源段编号、当前 bbox、已知失败键或对象数量。允许底板作为学习与回归样本，但必须走：样本特征提取 → 无量纲公式 → 运行时决策门 → 不同结构 DWG 证伪。

## 一次完整验收

从冻结零标注隔离副本开始，要求：

1. 一次加载和一次内部批处理；ARC/LINE 语义正确。
2. 所有运行时发现的可标段都有唯一映射和有效原生对象。
3. grip 2/3 端点关联及源几何漂移在合同容差内。
4. 第一遍普通排版完成，第二遍异常子集救援完成。
5. 特殊角度显示度数而非弧长；文字、箭头和标注弧线无不可接受拥挤。
6. 完整 native audit 与可读全画布截图均形成。
7. 分别报告生成、排版、观察、截图和总耗时。
8. 测试稿不保存；失败项隔离且不回滚已成功对象；同一 run 不自动重试。

## 成熟度边界

- `CAD-DIM-SPECIAL-TEXT-PEER-NORMAL-V2`：当前底板连续 3/3，证明固定公式与控制器可重复恢复同一类 grip-4 异常。
- 完整命令包：以 `config/command_packages/batch_polyline_dimension_v1.json` 的实时状态为准。
- 不同结构 DWG：未完成前必须明确写 `UNVERIFIED`，不得宣称通用。

## READY 与回传

- 只使用 `config/project_execution_index.json` 指向的当前 V8 READY 发布器。
- 目标任务 ID 只从 `config/cad_native_task_registry.json` 读取。
- 派发后项目回合结束，不轮询 CAD。
- 执行必须生成不可变回执并向项目任务回传；回传失败不授权重跑。
