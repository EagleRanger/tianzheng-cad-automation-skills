# CAD方法召回与证据边界

## 按对象召回

先读当前有效要求、输入/工作副本、最新纠正、保护项与保存停点，再按对象使用本包专项Skill和方法索引。只读相应类型与反例，不加载全部历史，不把旧任务对象或旧权限带入。无命中不等于没有方法，也不自动猜测执行器。

尺寸、半径、坐标、标高、索引、乔木与灌草各自持有真实语义；填充、文字、视口、数量、图审与交付也各保留自己的验收依据。以下公开文档相互独立、不依赖私人工程记录。

## 原生接口

命令输入点、实体夹点和文字定位点不是同一概念。先以RXCLASS、属性、实际显示子件与源几何识别语义，再使用当前已验适配器。原生三点、五点或多分支数量不能代替角色证明；静态API研究不证明实机支持，未知拓扑只停相关对象。

接口提交、SendCommand返回、CAD ACK/COMPLETE、原生实际修改、保存结果及图面验收分开结算。超时或未知副作用先对账，不能重放旧任务。窗口/进程/文档完整路径准确绑定，旧PID或同名标签不证明身份；未获前台授权不自动激活、切焦点或用鼠标输入。

## CAD-NATIVE-TEXT-READBACK-V1

此标识在本公共文档表示原生文字读回的必要约束，不是承诺已随包包含同名通用命令。主包若另带实现，应核其实际注册与版本。

按实际类型读取正文、测量值、单位、格式、上/下行、字体与原生显示子件，不用普通Text字段缺失的两次空值相等证明保持。文字接口读回只能证明它所覆盖字段，不能证明字形位置、轴向、箭头、真实包络或图面可见。显示子件内存测量后释放，不入库替代根对象。

遇中文数字混样、字体缺失、天正模块未渲染时，分清对象内容、宿主环境和捕获链。普通几何可见不等于天正文字可见；不可据空画布认定创建失败，也不反复补画或炸开。

## 填充先确认实际绿地

先从当前有效设计边界与实际道路/平台/岸界识别闭区，扣真实硬质及孔洞；轴线、红线和bbox不能替代有效绿地。新底板变更只重建受影响范围，不能搬旧HATCH自证正确。工作封口与真实工程外边分开，核相邻工程线穿入、首末漏填和分片覆盖。

原生格式、图案线定义/相位、面积与全段完整性分别验。[覆盖方法](../CAD_ANNOTATION_AESTHETIC_USER_REQUIREMENTS.md#a5-填充的边界格式与覆盖)要求独立应填集与实际填充差集，不宣称已有通用自动覆盖实现。

## 打印与目录收口

正式出图绑定实际文档、图框窗口、真实比例/纸张、CTB及视口显示；侧数据库设置成功不证明没有视口缓存串用。先试可辨识页，再按本次范围检查全幅与关键局部。图签、完整图号、图名、目录、承接详图、输出页序与交付文件逐项对应，不从文件名或圈号猜。

常规图审走已验原生区域截图，不自动打印、切前台或重开。确需打开冻结交付件诊断用临时副本；天正“不保存”退出也不天然等于容器字节不变。源字节保全仅在任务确有此约定时沿已有基线核，不每轮扫描全DWG。

完成后保护未存修改，按当前授权收拢本任务过程文档；用户验收后再关闭本任务独立宿主并核真实退出。共享宿主不误关其他对象，隐藏或仅关闭图纸不冒充进程退出。

## 适用条件和复发

一次经验至少保留对象/版本、方法、可测结果、已知反例与失效条件。新条件或反例只修失效处及真实依赖；未变成功范围复用。方法存在、召回可达、实际调用、效果合格与用户接受是不同证据。公开文档迁移和离线测试不证明当前CAD工程已完成。
