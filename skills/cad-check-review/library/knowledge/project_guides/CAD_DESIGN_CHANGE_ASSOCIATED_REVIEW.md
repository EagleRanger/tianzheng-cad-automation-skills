# CAD设计变更与关联校审

## 适用范围与成熟度

这是要求保真、来源区分、直接依赖和完整性审核的方法，不是新的执行器、工程设计依据或固定审批流程。原生技术有限定环境案例经验；本工作流的全链效果仍需当前实际批次验证，不宣称已经普遍降低返工或杜绝遗漏。业务权限仍取当前用户要求。

## 按用途锁依据

现状控制取本项目有效实测与坐标/高程基准；新平面和标高取明确有效变更；标准做法及图号取用户指定的配套详图；样式取当前合格模板和手改；编号、页码、专业与通知单取当前对应规则。一份文件可以只对某区域、某数据用途有效，不能笼统全文件优先。

当前用户纠正及具体例外覆盖其作用范围内旧要求，未受影响部分保持。来源冲突且影响结果只停该项，不从截图估数、按近邻补高程或擅定工程做法。

## 原要求到真实后态

沿项目原ID和[现有清单](../templates/CAD_执行清单模板.md)保留原话、配图、数值、范围、替代关系及独立后态。形状/大小/位置/内容/数量分别检查，不能从代码修改字段反推需求完整。

应有对象集从当前实际图中类型、角色、空间和本次范围独立建立，不只看执行成功列表。增加、修改、删除、保留、暂停和待核分开。动作可合批，验收仍逐原ID；执行自检不等于整套用户验收。

## 依赖顺序与关联矩阵

先保护当前稿与源，核有效控制点/几何/工程接口，再更新依赖填充、标注、数量、图幅和输出。前一步只核通过相应区域，后续据该区域接续；不为每个夹点新增审批。单项未知只阻断真实依赖。

| 变化 | 直接关联 | 检查边界 |
|---|---|---|
| 道路/平台线位或宽度 | 中边线、尺寸角度R、坐标、索引、填充、路缘/设施 | 追同一实物，不改指最近构件；清失效旧注，保必要新表达 |
| 标高/坡率或衔接 | 真实端点、坡向、长度、邻接构件、断面、相关专业接口 | 同一高程基准；百分坡度用`i=Δh/L×100%`前核L为相应水平长度，不混斜长/弧长/投影 |
| 坐标定位点 | 真实控制点、轴序、显示值、相关尺寸及搭接 | 纯样式调整则点/值冻结；换点需明确依据 |
| 断面/剖切 | 实际中心线或所切构件、方向、编号 | 终点/粗切线确实交到目标，不只碰轮廓或挪文字 |
| 做法/详图引用 | 每行源构件、全部落点、图号、承接页、必要范围框 | 按真实来源逐项，不全图字符串替换、不虚造分图号 |
| 绿化/硬质边界 | HATCH环/孔、首末接头、相关专业、有效面积 | 应填集独立建立，查漏填/越界，分幅不重复统计 |
| 植物或组别 | 唯一实物、树心、组线头尾、名称数量、图例表/备注 | 独立来源数量；不增删实体凑表 |
| 视口/分幅 | 当前范围、比例/旋转/冻结/裁剪、所有受影响注、索引目录 | 保工程WCS及用户手调；不同图种职责分别核 |
| 字号/符号/表格 | 原生Height/Scale、实际字形/符号、视口、缩印、表线/图名 | 不同类型比例不同；符号变大不带走真实点或固定文字 |
| 底图/显示 | 来源角色、原坐标、块层级、有效颜色、可见/打印、依赖解析 | 不把整层当同一角色，不以隐藏问题代替修复 |
| 页码/专业编号 | 图签、子系列、目录、实际页序、附图列表/文件 | 总册与子系列分别计，局部引用更改不扩为全套重编 |

进一步关联只在直接项确有变化时继续追，不默认全图重查。结构、水工、净空、过流等工程判断需要对应专业有效图及核算，本方法不生成缺失设计值。

## 完整性不能从结果自证

应填集合E来自有效设计，实际集合F从原生对象读取，分别查`E−F`、`F−E`。容差按本图单位、曲线表达和原生精度确定；读取失败不当空集，边界依据不足列待核，不填满bbox。

建立“应有对象/说明→实际原生实体→有效图幅→输出证据”的对应；逐行配文字、落点和真实线，不只核点数。源表相同不证明工程量正确，输出页数正确不证明图签总页数正确。

## 验收与局部返修

调用回执只证执行；原生读回证覆盖字段；几何检查证范围内关系；图面证受影响幅与风险局部可读；保存/按需重开证持久化；正式打印与文件对账证输出对应。以上不替代正式设计审批或用户接受。

先用已知反例验证失效判据，再核本次完整受影响范围。仅编号错只修对应引用，符号错修原生形状与保护项，源几何/高程错回到有效依据并重核真实下游。常规保存后当前文档继续，具体异常/恢复/明确重开要求才重开；PDF仅本次明确需要时生成。

## 协作与交付

单对话可使用同样要求/执行/检查分阶段；只有用户明确采用分工时才交接，不自动新建聊天/委派。始终单一CAD写入者、同一份要求记录、串行合入检查，交接发送成功不等于实际落实。

未完、暂停、待核和已撤回留原项，说明真实阻碍和恢复条件。已授权范围内能继续的独立工作继续，局部通过不宣布整套完成。交付只按当前要求的文件、分册与形式，不顺带发布或改原件。
