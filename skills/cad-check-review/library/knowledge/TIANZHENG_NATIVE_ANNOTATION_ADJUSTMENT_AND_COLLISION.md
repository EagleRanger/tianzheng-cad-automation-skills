# 天正原生标注控制与失效边界

公开方法文档，不含CAD执行入口或工程任务文件。以下实机经验主要来自T20 V10 + AutoCAD 2021的限定模板；不是任意天正版本、所有夹点拓扑或任意DWG的能力证明。API名、静态研究及数学规则分别标明，不以静态线索覆盖实际RXCLASS。运行仍需本机合法完整CAD/天正环境和当前准确对象授权。

## 园建原生控制

先核当前文档、源对象、用户手改及所属模型/纸空间。对象需真实来源资格，再按[图面方法](CAD_ANNOTATION_AESTHETIC_USER_REQUIREMENTS.md#n08-语义去重与源资格)进入排版。原生属性先设，几何每次移动后重读夹点与显示组件；不能把旧差值批推当真实联动。

- `TDbDimension2`先核沿边/投影方向、源端点、顺逆与bulge；原生显示角度与几何均核。反角不能靠盖字或猜测交换旧端点假修复。
- `TDbRadiusDim`保圆心及同一源弧，按实际径向控制尺寸线、文字保持默认联动；不得复用曾发生致命错误的Reset/猜测ABI调用。
- 单落点`TDbSymbIndexPointer`限定模板的g2为指向、g1折点、g0承托端；g1会带动g0，先真实指向再折点最后承托，逐次重读。额外终端横杠或多分支不能套此三点。
- `TDbSymbCoord`限定模板g0为测点。移动g0未必更新坐标显示值，纯排版锁g0和值；换真实点才按本图已证轴序同步原生数值。
- 普通层名、命令名及夹点数量不证明对象语义；字体、图名、表格及临时显示组件须按实际原生类型控制。

## 原生单源灌草引出

限定实测：T20 V10 + AutoCAD 2021的单源`TDbSymbMultiLeader`具有保存重开及实际图面经验；不扩展到多锚点、多分支或其他版本。优先改已有原生整体，需替换时克隆当前合格原生模板，实际新后态合格后才按归属清旧散件。

本模板g0为折点/承托起点、g1为承托远端、g2为有效分区锚点，其他为文字控制；增加下行可能增夹点，多锚点也可能同样点数。须结合真实显示组件辨认。

读取`UpText / DownText / Height / Scale / LayoutRotation`及`GripDataCollection`。先属性，按本模板g0→g1→g2调整；每次重取当前夹点，以`target-currentGrip`调用`MoveGripPointsAt`。一般让文字随承托，不独立拖散。该接口的`LayoutRotation`实测用度，不能仅`TransformBy`就假定原生文字方向已设置。

天正面积上标实测采用`m^U2^U`；上下行分别写UpText/DownText，不能拿MText换行符当通用控制。名义Height和Scale不等于不同类型真实字形高，按当前视口、合格样本及显示组件校准。上下行字形分别测，空白行隙不作为实字障碍。

## 坐标标注

先确认真实坐标系、轴序、单位及精度；世界/用户/场地坐标不能默认沿用会话残留。实测对象类型为`TDbSymbCoord`。静态命令研究出现的同名接口只作线索，不能据此强制换成索引类型。

限定模板测点g0、折点g1、承托端g2；镜像、分支与版本变化后先核实际线段拓扑。某样本XValue对应模型Y、YValue对应模型X，是项目轴序，不是默认。只调显示保持真实点和值，改测点必须同步当前已核轴序并检查显示舍入。

单源外引按90°优先、0°水平或45°斜引模式执行。内角取从真实折点出发的相邻两射线，不用补角、绝对点积或错误承托方向掩盖锐角。跨幅完整性取当前项目约定，不为让所有重叠幅都显示而擅改点或复制注。

## 坐标符号形状

限定T20 V10 + AutoCAD 2021样本中，COM Style表示坐标文字形式，不能证明定位符号形状；原生`GetStyle/SetStyle`控制定位图形。实测圆点与十字的枚举值分别为1、3，仅作该版本模板的已知观察，未知版本必须从当前合格样本读取并做代表对象验证，不猜ABI或枚举。

形状、纸面尺寸、符号中心、文字/引线、坐标值独立核。真十字应由实际两条垂直线及其交点核到测点；只放大Scale/TextHeight不是切换形状。不能叠假十字或炸开；符号大小调整若联动文字，应按已证方式补偿并恢复原夹点，检查实际显示而非仅属性值。

## 半径标注

静态研究提示原生命令会对子弧内部拾取点做命中检测，整条多段线句柄不足以锁定子弧。批次应给当前源身份、子段及真实拾取点。`SetDimCenter / SetDimEndPoint / SetDimLen / SetTextPos / GetDefaultTextPos / SetDiameter`是接口线索，不是本包跨版本调用保证。

限定实机`TDbRadiusDim`样本：g0圆心，g2源弧标记/径向控制，g1尺寸线辅助端，g3文字。移动g2后g1投影到同一径向，g3按默认文字关系联动。先调整径向控制并读回，仍有真实特殊文字冲突才按当前许可末级微调g3。

参数化观察为`θ=θ_start+f·sweep`、`P2=C+R(cosθ,sinθ)`、`L=normalize(P2-C)`，文字基线方向为可读的`upright((-L.y,L.x))`，保持`dot(L,T)=0`；默认文字位置由原生状态确定，不把某次距离硬编码。核圆心、源弧、实际R值、同向径向关系及字形，而非仅命令返回。

按配对尺寸数字边缘净距生成半径的策略，只在采用该已验策略的当前任务中沿局部垂线伸缩/换侧；切向横移需重新选同弧拾取点并受保护重生成，不能冒充同一个径向标量任务。其他已确认模板策略不被此观察强制覆盖。

## 总图双圈索引

一个原生索引承载双圈时，正文、两圈真实图号及当前承接页分别核。限定实测模板先写第二圈图号，再移动外圈控制形成第二圈，最后写第一圈；`DrawingLabel`只改第一圈。旧样本曾因移动过大出现第三圈，不存在公开通用步长公式。本包不提供历史圈径、移动量或图号默认。

未知圈径/版本先在隔离代表对象核原生圆显示组件、图号及夹点联动，不能用复制圆和普通文字冒充。外部属性枚举曾伴随RPC错误和宿主退出，仅确认时间关联、未证明内部根因；不要在生产宿主试探未知枚举/ABI。

## 多落点说明

`TDbSymbComposing`的文字行、落点、源构件必须逐项配对，行数或无序点集相等不证明语义正确。限定反例中最高控制点越过其他落点会删除控制点；某模板需先从低到高设置其他点，最后最高点。另一完整模板存在不同恢复顺序，不能合成通用夹点序。

先读当前纸面排序和真实拓扑，克隆完整合格模板；每步重读，点数减少、文字/分支丢失立即停该对象并保护。原生返回顺序可能变化，不能永久固定后续夹点为某行。模型/纸空间统一投影至真实可见视口，排除系统纸空间总览缓存；检查块内普通文字、索引圈、分支及邻幅，不只核新对象。

## 纸面符号与剖切

不同原生类型的ArrowSize、CirPointSize、Scale与纸面尺寸关系不同。读取真实显示几何并经覆盖视口换算；保符号圆心、文字、线及未改几何。剖切的终点应与真实目标曲线求交，原生联动可能翻转另一端，最后重读全部实际终点和文字承托关系。不固化某模板夹点序。

## 填充与视口的限定反例

新视口直接Clone曾共享内部视图状态；采用当前已验原生独立建立方式后设置Target、ViewCenter、CustomScale、Twist、裁剪与冻结集合，再看实际图面。运行时Number或冻结列表次序变化不能单独判设计变化。

填充先认有效边界，隔离工作平面、扣硬质、精确逆移。微缺口容差需来自本图单位和精度；不带入历史吸附阈值。原生HATCH格式正确与全段覆盖完整分验，详见[覆盖方法](CAD_ANNOTATION_AESTHETIC_USER_REQUIREMENTS.md#a5-填充的边界格式与覆盖)。

原生显示组件提取后DBMOD可能变化而根对象未变，不能单值判定。只读/不保存关闭也不天然保证冻结文件字节不变；确需打开冻结交付件时用临时副本。常规修改保存后继续当前文档，重开按明确持久性问题或任务要求触发。

## 证据与适用性

本包提供方法和有限纯几何检查，不提供未知宿主的完整天正初始化证明。模型捕获能看到普通几何不等于能显示天正文字；模块加载请求不等于成功加载。实际原生类型、语义、联动、当前布局图面、保存结果分别取证，缺显示能力只阻塞依赖它的验收，不重复补画、炸开或擅用前台。
