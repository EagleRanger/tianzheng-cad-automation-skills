# 原生标注近带偏移合同

## 输入与适用性

先核当前源段、测量方向、边线/中线角色、实际字高H、文字有效厚度Ttarget、真实道路全宽W、局部容量和合格样式。H取当前显示字形及[覆盖视口](CAD_ANNOTATION_VIEWPORT_SCALE_CONTRACT_V1.md)校准，不能只读DIMTXT或拿历史模型字高。

这是已采用近带方法的抽象，不提供所有图纸统一带宽或自动设计分类。历史参考图统计不是跨图默认，工程宽度、容差和候选带必须由当前规则/样例提供。

## 普通分支

已采用的普通下界：

`O_min=max(W/2+H/3+Ttarget+H/3, 1.6H)`。

普通边线按该策略W=0，中线使用真实W；H、Ttarget、W必须在同一模型尺度。将O_min向上取当前已验候选带中最近可用者。没有当前候选带或文字厚度依据时列方法缺口，不补历史统计值、不将某次取带结果设固定常数。

无真实障碍时用最近合理带，连续同侧保持秩序；有冲突先区分文字、构筑物与软背景，再局部换侧/错层或升一档。不为零交点扩大整图搜索，不为半径避让反向推远合理角度带，不缩小字体掩盖冲突。

另一个仅表示边线净距的通式`O=W/2+K×H`，K为当前已验净距系数，不与上式候选带下界混为独立新算法。道路半宽是真实几何，不再乘纸面比例。

## 原生语义与异常子集

ARC表达圆心角度数，LINE表达长度，R表达真实源弧半径；测量错误不能靠排版修复。主要轮廓和必要角度/尺寸先稳定，再排R、坐标、索引。

普通文字随原生尺寸线自动布局。只有运行时识别的坍缩/文字不随动异常才局部救援；可用同源有效邻居的`文字—尺寸线法向偏距/H`还原目标H下位置，输出明确WCS位移，不让控制器二次解释。不改已正确的曲线姿态、冻结对象或整套普通带。

半径的径向标量任务按径向合同验，完整向量任务按完整向量验；不能用未受控切向差误拒径向任务，也不能只看半径掩盖错误切向移动。

## 验收与非承诺

规划无碰撞只证明给定输入下的离线结果。原生落图后核真实测量、源映射、夹点/文字联动、修改范围、当前布局实际图面和保存结果。重开仅在持久性异常、恢复或明确任务要求时执行，不从历史验收门复制例行重开。

单一模板、局部重复或若干预检通过不证明完整命令跨图稳定；候选带、文字厚度、源资格和原生适配仍需当前环境实际证据。此文没有新增CAD执行能力。
