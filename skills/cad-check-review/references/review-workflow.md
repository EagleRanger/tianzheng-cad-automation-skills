# CAD校审检查框架

## 1. 先锁定检查依据

记录用户指定的图纸、版本、统计口径和权威来源。其他扫描结果只能作为交叉核对，不得混入最终统计。

将问题分为：

- 已确认错误：直接证据足以证明冲突。
- 待核问题：存在差异，但权威名称、规格、设计意图或修正值未确认。
- 检查提示：不一定错误，但需要人工复核。

## 2. 常用检查域

### 图例与填充

- 同一植物或材料是否使用统一图案。
- 同一边界是否存在完全重叠的双填充。
- 图案名称、比例、角度、边界和面积是否与图例一致。
- 图例表格格内是否存在两个填充对象。

### 引出标注与数量表

- 名称是否完全一致，注意别名、错字和近似名称。
- 引出标注累计值是否等于数量表。
- 某项是否被合并到另一行，或表内缺少独立行。
- 数量、面积、单位和规格是否同时存在。

### 平面对象与统计

- 引出标注数量与块参照数量是否一致。
- 块名是否与标注名称一致。
- 重复区域、复制区或汇总区是否需要剔除。
- 专有天正对象是否被普通对象扫描漏掉。

### 图层与几何

- 对象是否位于正确图层、空间和坐标范围。
- 是否存在断线、重复线、零长度对象、异常远点或跨区包围盒。
- 修改前后目标对象的句柄、顶点、长度、面积或对象类型是否符合预期。

## 3. 问题台账字段

建议使用 TSV/CSV/JSON，字段至少包括：

`issue_id, status, category, subject, observed, expected, evidence, handle, layer, bbox, confidence, proposed_action`

`expected` 不明确时留空，并把 `status` 设为 `待核`。不要为了表格完整而推测数值。

## 4. 证据优先级

1. 用户当前明确口径或修改要求。
2. 图内原生对象属性、句柄和几何。
3. 同图中的表格、图例和引出标注相互印证。
4. 设计规范或外部资料。
5. 助手推断。

低优先级证据不得覆盖高优先级依据。

## 5. 修改后的回归检查

- 精确对照修改对象清单，确认未新增计划外对象。
- 检查所有原有关键对象仍存在且类型未改变。
- 正式保存后立即固化候选及哈希；复制临时副本做关闭、重开和重复统计。
- 再复制一个临时副本截取局部画布，直接检查视觉结果和可编辑性。
- 天正即使显示 `DBMOD=0` 或选择“不保存”，退出阶段仍可能重写容器；审计与截图副本的退出后哈希不能替代固化候选哈希。
- 再次计算源图哈希，确认正式源文件未改动。
