# 原生校审与交付：近期可迁移实践

本版将已经进入原项目方法入口的经验去标识化整理，不附项目图纸、专有插件或私有运行链。主要实测环境为 T20 V10 / AutoCAD 2021；其他版本、图纸拓扑和适配器须重新确认。

## 1. 先认用途，再认原生整体

材料引出、台阶方向、图名、图号索引、坐标、半径和尺寸并非一种文字排版任务。先识别真实来源与用途，保护源关联，再选对应原生类型。不能把台阶说明移到无关空地，也不能用文字加折线冒充可编辑天正整体。

同图兼容模板可以作为样本，但完整多落点拓扑须逐点读回。单分支的夹点数、序号、轴序和控制顺序不能直接套给多分支对象。图名、下划线、比例按同一原生整体及联合范围校核；增加索引、图例或备注后复查位置。

## 2. 区分语义移动与仅排版

仅排版时冻结真实锚点、量测端点、数值与源关系；移动文字、折点后重新读回实际原生状态。需要移动真实坐标锚点时，按当前图纸已验证轴序同步核对坐标数值。用户手动锁定的箭头端点不能为避碰擅自改动。

自由引出的折角按非退化、直角或钝角关系核验；旋转视口使用一致坐标变换，不能用绝对值掩盖反折。真实成员节点的物理串线与自由外引出分开判断，不能为了让每个节点都满足同一角度而挪设计对象。

尺寸先核真实测量端点及沿边/投影方向，再调尺寸线；显示高从实际文字部件判断，不把Height、Scale或DIMTXT任意一个字段当作唯一显示高度。不能覆盖文字来伪造正确量测。

## 3. 检查实际可见的跨类型冲突

按实际目标视口纳入普通文字、天正显示部件、嵌套块文字、底图桩号、箭头、线和无文字引线。根对象零冲突、非空缓存或截图亮度都不能替代这一范围。空字符串不是删除依据；先区分有效符号、定位线和确实无用的残留对象。

用旋转文字框、箭头顶点及线段关系细化粗略AABB/像素筛查；有意交点和真实锚点关系不能机械算成避碰失败。按对象与图层解析有效颜色，不凭图层名称或单字段猜颜色。

## 4. 当前用户稿优先，变更连同关联项复查

新建、删除、换号和整组位置以当前手改稿为准。旧数量、旧图号或旧截图不是恢复已删对象的理由。对明确改动检查关联图例、索引、数量表、图签及相邻专业接口；缺设计依据的数值保持待核，不自动补成“合理值”。

## 5. 原文档打印与全册核对

先核准确文档、活动数据库、实际图框、纸张、方向、视口比例和本册打印样式。试打一个能识别内容的页面，再按范围输出；某些经测跨文档路径会误用活动视口缓存，参数正确不证明画面正确。不能把这个已知问题扩大为所有侧数据库路线必然失效。

打印灰度、淡显和线型从本项目要求取得，不把历史纸张、颜色号、比例或淡显百分比设为通用常数。目录从当前正式图签读取完整图名图号，真实XLS交付不能以CSV/HTML改扩展名代替。PDF替换时核变更页及应保持原样的页。

## 6. 固化候选与独立重开

保存后冻结候选和哈希，审计及截图只打开另外的临时副本。天正可能在DBMOD为零或不保存退出时重写容器；审计结束后核对固化候选和源文件，不能直接把被会话重写的副本提升为交付稿。

只读观察可能影响临时显示部件或DBMOD。先核实际对象、样式、源关联与容器差异，不以DBMOD单值推断一切。保存、几何重开、文字语义、视觉结果和用户认可分别留证；文字读取为空或零样本不等于文字审计通过。

## 7. 后台与窗口收尾

复用适用后台接口；异常、弹窗或截图需求不自动授予焦点、键鼠或界面操作权限。工具名称不能证明无前台影响，须核实际函数和当前授权。单窗口固定只读采样不能推广成任意业务命令、多窗口寻址或并发写入通过。

按用途及时收拢本任务打开的参考、过程和审计稿，保留用户要求及仍需使用的文档。关闭前核精确路径、进程和未保存状态；需要时先另存可恢复副本，读回保存成功后逐文档关闭，并重新列出剩余文档。不得为清理窗口杀整个CAD或误关用户正在编辑的图。

## 8. 接收方需要自行补齐的部分

本包提供框架、校审脚本与批量标注接入合同，不含完整私有生成器、主机绑定、专有DLL或真实图纸。未验收的多窗口/双任务并发、完整批量三遍与跨DWG通用性保持未验证；新电脑仍须做精确实例绑定、局部原生对象、保存重开和真实图面验收。历史许可、样本计数、夹点编号和内存句柄均不可复用为当前常量。
